# Superstore Sales Performance Dashboard

Built an interactive Excel dashboard using the Sample Superstore dataset (9,994 rows).

## Skills Used
- Excel Tables, XLOOKUP, SUMIF, COUNTIF
- IF and Nested IF logic
- Dynamic Arrays (FILTER, UNIQUE, SORT)
- Pivot Tables with Slicers
- Power Query for data transformation
- Dashboard design with KPI cards and charts

## Key Insights
- West region has highest total sales ($725K)
- Technology is the top-selling category ($836K)
- Average discount given is 15.6%
- Total profit margin is 12.5%
